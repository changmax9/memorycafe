# Memory Café

Memory Café is a playable AP Psychology web game about working memory limits and chunking. The player studies a café order at a coffee shop counter, waits for the customer's order bubble to disappear, and then rebuilds the sequence from memory on the serving tray. Later levels unlock grouped menu shelves so players can experience chunking as a memory strategy.

## Run the Project

```bash
npm install
npm run dev
```

Then open the local URL shown in the terminal, usually `http://localhost:5173`.

## Gameplay

- Study each active customer's order bubble before the café clock runs out.
- Rebuild the exact sequence by clicking counter menu cards.
- Watch selected items appear in numbered tray slots.
- Submit the order to see how many items were correct by position.
- Later levels add longer orders, distractors, similar item names, and grouped choices.
- Use the Psychology Check button for a quick teacher-facing explanation.

## Psychology Connection

- Disappearing orders represent working memory.
- Longer orders and distractor choices increase cognitive load.
- Grouped categories represent chunking: organizing information into meaningful units.
